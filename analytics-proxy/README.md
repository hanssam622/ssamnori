# 쌤노리 공개 통계 API

이 Apps Script는 GA4 원본 데이터에 대한 인증 정보를 공개하지 않고, 사이트에 표시할 합계만 JSON으로 제공합니다.

1. Apps Script 프로젝트를 만들고 `Code.gs` 내용을 붙여 넣습니다.
2. 프로젝트 설정에서 `appsscript.json` 표시를 켜고 이 폴더의 manifest 내용으로 교체합니다.
3. 배포 > 새 배포 > 웹 앱에서 실행 사용자를 `나`, 액세스 사용자를 `모든 사용자`로 설정합니다.
4. 배포 URL을 루트 `stats-config.js`의 값에 입력합니다.

통계는 한 시간 동안 캐시되며 2026-09-14 이후 데이터만 집계합니다.
