이어온, 이렇게 달라졌어요

기존의 번역·음성·HTML 수업자료 만들기는 그대로입니다. 기록을 관리하는 화면을 새로 정리하고, 교과서와 PPT를 가져오는 방법을 늘렸습니다.

예전 버전과 달라진 점

새 메인 화면
왼쪽에서 기록을 고르고, 가운데에서 본문을 확인한 뒤 아래의 전체 처리 줄에서 필요한 작업만 선택합니다. 번역·단어사전·음성·HTML과 진행 상태가 한곳에 모였습니다. 웹 기반 화면이 기본이고, 실행이 어려운 환경에서는 클래식 화면을 이용할 수 있습니다.
작업마다 AI 선택
위쪽 AI 연결에서 전체 작업의 기본 공급자를 고르거나, OCR·문장 잇기·번역·단어사전만 따로 바꿀 수 있습니다. 제미나이 웹과 Gemini API를 구분하고, 준비된 GCP 연결도 사용할 수 있습니다. 음성과 NotebookLM은 별도 설정입니다.
교과서 OCR과 문장 위치
글자가 들어 있는 PDF는 파일 속 글자 그대로 가져오고, 스캔본은 OCR로 읽습니다. 한 문장이 여러 줄이나 페이지에 걸쳐 있어도 문장과 영역을 연결하도록 개선했습니다. Gemini OCR 외에 Document AI·Cloud Vision을 선택할 수 있고, 로컬 글줄 검출과 제미나이 웹을 조합하는 무료 OCR도 추가했습니다.
PPT HTML 가져오기
PPT의 내부 글자는 직접 가져오고, 그림에 들어 있는 글자만 OCR하는 선택지가 생겼습니다. 중복 그림 제외, 글꼴 확인·변경, 도형·표·말풍선 재현도 개선했습니다. 기존 슬라이드 이미지와 클릭 단계별 가져오기는 유지합니다. 새 HTML 가져오기와 무료 OCR은 테스트 기능입니다.
자동·반자동·수동
자동 진행은 제미나이에 입력하고 결과를 받는 과정까지 이어집니다. 반자동은 프롬프트와 그림을 이어온이 준비하고, 선생님이 전송과 답 복사를 맡습니다. 수동 외부 LLM 흐름도 남아 있어 자동 연결이 불안정할 때 선택할 수 있습니다.
진도표와 수업자료
진도표에서 만든 기록은 그룹으로 확인하고, 저장된 PDF·배정 페이지를 다시 불러오거나 필요한 차시를 다시 만들 수 있습니다. 단어사전에서 단어카드·연습장·워드캐쳐 전송을 찾고, 도구 → PPT 음성 넣기에서 기존 음성 배치 기능을 이용합니다.

업데이트 후에도 최종 결과는 확인해 주세요. AI 번역과 OCR은 자료에 따라 오류가 날 수 있습니다. 특히 PPT의 복잡한 효과·글꼴·그림은 실제 PowerPoint 화면과 차이가 생길 수 있습니다.

무료 OCR은 글줄 위치를 로컬에서 찾고, 본문 인식은 제미나이 웹에 맡기는 방식입니다. 인터넷과 구글 로그인이 필요합니다. 유료 API 기능은 선택한 공급자의 계정·키 설정과 요금 조건을 확인하세요.

다운로드와 업데이트

설명서 위쪽의 Windows 3.12.2 다운로드는 Google Drive에 저장한 GitHub 릴리스 설치파일입니다. EaronSetup-3.12.2-windows-x64.exe를 내려받아 실행하세요.

설치 전에는 진행 중인 작업을 마치고 이어온을 종료하세요. 중요한 기록과 결과 폴더는 별도로 백업하는 것을 권장합니다. 이 링크는 Windows용이며 Mac 설치파일이 아닙니다.

기능 요약은 배포 기록과 구현 내역을 기준으로 작성했습니다. 웹 자동 진행은 외부 서비스 상태에 따라 실패할 수 있으며, 자동·반자동·수동 중 상황에 맞는 방법을 선택하세요.
