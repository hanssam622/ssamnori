이어온 3.03 · 처음 쓰는 선생님께

이어온 빠른 시작

네 단계면 번역, 음성, 수업용 HTML이 나옵니다.

  1. 제미나이 로그인

    오른쪽 아래 gemini / 노트북 로그인을 누르고, 열린 창에서 구글 계정으로 로그인합니다. 초록불이 켜지면 됩니다.

    처음 한 번 해 두면 됩니다. 나중에 초록불이 꺼져 있으면 다시 누르세요.

  2. 자동 진행 체크

    위쪽 줄의 자동 진행에 체크합니다. 제미나이에 묻고 답을 받아오는 일을 이어온이 알아서 합니다.

    API 키 없이 쓰려면 왼쪽 스위치가 외부 LLM이어야 합니다. 처음 설치하면 API로 되어 있으니 한 번 눌러 바꿔 주세요.

  3. 텍스트 쓰기, 또는 PDF·PPT 끌어다 놓기

    텍스트

    입력창에 본문을 쓰거나 붙여 넣고 ▶ 전체 처리를 누릅니다.

    PDF · PPT

    파일을 입력창에 끌어다 놓으면 바로 시작합니다. 여러 개를 한꺼번에 놓아도 차례로 처리합니다.

    진행하는 동안 제미나이 창이 잠깐씩 떴다 닫힙니다. 그 창은 닫거나 건드리지 마세요.

  4. 기록 우클릭으로 결과물 열기

    끝난 기록은 왼쪽 번역 기록의 완료에 있습니다. 기록을 우클릭하세요. 맥 트랙패드는 두 손가락으로 누릅니다.

    HTML 결과 열기

    학생 휴대폰용

    NotebookLM 노트북 열기
