이어온 3.03 · 선생님용 안내

이어온 사용설명서

교과서 PPT·PDF를 창에 끌어다 놓거나 본문을 붙여 넣으면, 번역과 단어사전, 원문·번역 음성, 수업에 바로 쓰는 HTML까지 한 번에 만들어 줍니다. 자주 쓰는 기능만 골라 담았습니다.

처음 한 번만

아래 다섯 가지만 맞춰 두면, 다음부터는 자료를 끌어다 놓기만 하면 됩니다.

  1. 위쪽에서 외부 LLM을 고릅니다.API 키 없이, 선생님 계정의 제미나이로 처리합니다.
  2. 오른쪽 아래 gemini / 노트북 로그인을 눌러 구글 계정으로 로그인합니다.로그인 상태에 초록불이 켜지면 됩니다.
  3. 출발어와 도착어를 고릅니다.예: 한국어 → 러시아어. 학생의 모국어가 도착어입니다.
  4. 자동 진행에 체크하고, 옆의 ⚙에서 작업 범위를 OCR + 번역으로 둡니다.
  5. 아래쪽 단계 줄 왼쪽에서 전체를 고릅니다.번역·단어사전·슬라이드·음성·HTML이 모두 켜집니다.

이제 PPT나 PDF를 이어온 창에 끌어다 놓으면 끝까지 알아서 진행됩니다.

화면 둘러보기

번호를 따라 한 번 훑어보세요. 자세한 설명은 아래 각 항목에 있습니다.

외부 LLM

번역과 글자 인식을 누구에게 맡길지 정하는 스위치입니다.

외부 LLM 대부분 이쪽

선생님이 로그인한 제미나이(또는 ChatGPT) 웹을 씁니다. API 키도, 사용료도 필요 없습니다.

API

이어온이 번역 서버에 직접 요청합니다. 왼쪽 위 API에 키를 넣어야 하고, 쓴 만큼 요금이 나옵니다.

외부 LLM은 이렇게 돌아갑니다

자동 진행이 켜져 있으면 이어온이 제미나이 창에 직접 묻고 답을 받아옵니다. 선생님이 손댈 일이 없습니다.

자동 진행을 꺼 두었거나 답을 자동으로 받아오지 못하면 외부 작업 창이 열립니다. 이때는 손으로 한 번 오가면 됩니다.

  1. 프롬프트 복사를 누르고, Gemini 열기(또는 ChatGPT 열기)로 연 창에 붙여 넣어 보냅니다.
  2. 답이 나오면 답 전체를 복사합니다.
  3. 클립보드 붙여넣기 → 결과 적용을 누르면 나머지 단계가 이어서 진행됩니다.
답은 원문 한 줄, 번역 한 줄이 번갈아 와야 합니다. 앞뒤에 인사말이나 설명, 번호가 붙은 답은 적용되지 않습니다. 그럴 땐 답을 다시 받아 주세요.

제미나이 로그인

자동 진행과 NotebookLM을 쓰려면 한 번 로그인해 두어야 합니다.

  1. gemini / 노트북 로그인을 누르면 브라우저 창이 하나 열립니다.
  2. 구글 계정으로 로그인합니다. 로그인이 확인되면 창은 저절로 닫힙니다.
  3. 로그인 상태에 초록불이 켜지는지 봅니다. 안 바뀌면 새로고침을 눌러 보세요.
  • NotebookLM은 따로 로그인하지 않습니다. 제미나이에 로그인하면 같은 계정으로 함께 연결됩니다.
  • 이어온이 쓰는 브라우저는 평소 쓰는 크롬과 별개입니다. 크롬에 로그인돼 있어도 여기서 한 번은 로그인해야 합니다.
  • 다른 계정으로 바꾸려면 로그인 버튼을 누르고, “이미 로그인된 계정이 있습니다” 창에서 예를 누릅니다.

전체 처리

편집창 아래 단계 줄에서 만들 것을 켜고 ▶ 전체 처리를 누릅니다. 왼쪽부터 차례대로 진행됩니다.

외부 번역

원문을 문장 단위로 다듬고 도착어로 번역합니다. API 모드에서는 이름이 번역으로 바뀝니다.

PPT·PDF를 끌어다 놓은 경우에는 글자 인식과 번역이 함께 이루어지므로, 이 칸을 켜 두었든 꺼 두었든 똑같이 진행됩니다.

단어사전

본문에서 학생에게 필요한 단어를 30개 안팎으로 골라 뜻과 예문을 붙입니다. 예문은 본문 문장에서 가져옵니다.

오른쪽 빠른 실행의 단어사전으로 열어 보고, 고치거나 더 만들 수 있습니다.

NotebookLM ▾

이름을 누르면 만들 슬라이드를 고를 수 있습니다. 병기 슬라이드는 원문과 번역을 함께, 본문 슬라이드는 원문만, 단어 슬라이드는 단어사전으로 만듭니다.

슬라이드는 몇 분 걸려서 나머지 작업과 따로 진행됩니다. 음성과 HTML은 슬라이드를 기다리지 않고 먼저 나옵니다. 슬라이드가 실패해도 다른 결과물에는 영향이 없습니다.

TTS

원문과 번역을 문장마다 읽어 주는 음성을 만듭니다.

HTML

수업 화면에 띄우는 카드형 HTML과, 학생 휴대폰용 모바일 HTML을 만듭니다. 단어사전이 있으면 단어 탭도 함께 들어갑니다.

단계 줄 맨 왼쪽 목록은 체크를 한꺼번에 바꿔 주는 단축키입니다. 고른 뒤에 칸을 따로 켜고 꺼도 됩니다.

결과물 찾기

작업 목록에서 기록을 우클릭하면 됩니다.

  • 결과 폴더 열기 — 음성, 단어사전, 슬라이드 파일이 모두 여기 있습니다.
  • HTML 결과 열기 · 모바일 HTML 열기 — 수업 자료를 바로 엽니다.
  • NotebookLM 노트북 열기 — 슬라이드가 만들어진 노트북으로 갑니다. 아직 준비 중이면 흐리게 표시됩니다.

자동 진행

켜 두면 자료를 넣는 순간부터 결과물까지 묻지 않고 진행합니다.

무엇이 자동으로 되나요

  • PPT·PDF를 끌어다 놓으면 파일마다 기록이 생기고 대기열에 들어갑니다. 슬라이드를 이미지로 바꿔 제미나이에게 글자 인식과 번역을 맡긴 뒤, 켜 둔 나머지 단계를 끝까지 진행합니다. 여러 파일을 한꺼번에 놓아도 순서대로 처리합니다.
  • 본문을 붙여 넣고 전체 처리를 누르면 제미나이 창에서 정리와 번역을 받아옵니다. 열린 기록이 없으면 첫 줄로 이름을 지어 새 기록을 만듭니다.
  • 진행 중에는 제미나이 창이 잠깐씩 떴다 닫힙니다. 그 창은 닫거나 건드리지 마세요.

자동진행 설정 (⚙)

  • 작업 범위 — OCR + 번역을 권장합니다. OCR만이면 번역문이 오지 않아 음성과 HTML을 만들 수 없습니다. 이 상태로 PPT를 놓으면 이어온이 바꿀지 먼저 물어봅니다.
  • 인식 단위 — 문장 단위를 권장합니다. 한 문장씩 카드와 음성이 됩니다.
  • 이미지 첨부 방식 — 보통은 자동에 둡니다. 제미나이에 이미지가 올라가지 않을 때는 파일 업로드 버튼이나 이미지 클립보드 복사·붙여넣기로 바꿔 보세요.
  • 배치 크기 — 한 번에 제미나이에 보내는 슬라이드 수입니다. 기본 10장이면 충분합니다.

중간에 멈췄다면

왼쪽 이어서 보내기를 누르면 멈춘 곳부터 다시 보냅니다. 이미 받은 부분은 다시 보내지 않습니다.

문제가 생기면

자주 묻는 경우부터 적었습니다.

로그인이 풀렸다고 나와요

로그인 상태가 빨간불이거나 “로그아웃 상태로 열렸습니다”라고 나오면, gemini / 노트북 로그인을 다시 눌러 로그인해 주세요.

슬라이드가 안 만들어지고 “server rejected this request”라고 나와요

NotebookLM 계정의 노트북 개수가 한도에 찬 것입니다. 기록마다 노트북이 하나씩 생기니, NotebookLM에서 지난 노트북을 지우면 다시 만들어집니다. 번역·음성·HTML은 이와 관계없이 정상적으로 나옵니다.

제미나이에 프롬프트만 들어가고 이미지가 안 올라가요

⚙ 자동진행 설정에서 이미지 첨부 방식을 다른 쪽으로 바꿔 다시 해 보세요.

진행이 멈췄어요

이어서 보내기로 멈춘 곳부터 다시 보낼 수 있습니다. 오른쪽 작업 진행 칸에 어느 단계에서 멈췄는지 나옵니다.

원인을 알고 싶어요

이어온이 한 일은 날짜별 로그 파일에 모두 남습니다. 문의하실 때 그날 파일을 함께 보내 주시면 원인을 바로 찾을 수 있습니다.

Windows%USERPROFILE%\.earon_app\logs
Mac~/.earon_app/logs
