이어온 3.12 · 사용 설명서

제미나이 웹으로 수업 자료 만들기

API 키 없이, 구글 계정 로그인만으로 번역·단어사전·음성·수업용 HTML을 만듭니다. 다섯 단계입니다.

  • 준비물은 구글 계정 하나입니다.
  • 이어온이 제미나이 창을 직접 열어 묻고 답을 받아옵니다.
  • 본문 텍스트, PPT, PDF 모두 같은 방법으로 넣습니다.

  1. 제미나이에 로그인하기

    오른쪽 위 제미나이 웹 · 로그인 필요를 누르고, 제미나이 / 노트북 로그인을 누릅니다. 열린 브라우저 창에서 구글 계정으로 로그인하면 됩니다.

    처음 한 번만 하면 됩니다. 로그인은 컴퓨터에 남아 다음에 이어온을 켜도 그대로입니다.

  2. 초록불과 자동 진행 확인하기

    오른쪽 위가 제미나이 웹 · 연결됨(초록불)으로 바뀌었는지 보고, 아래 줄의 자동 진행 스위치를 켭니다. 자동 진행이 켜져 있으면 제미나이에 묻고 답을 받아오는 일을 이어온이 알아서 합니다.

    칩을 누르면 그 단계를 켜고 끕니다. 처음에는 그대로 두어도 됩니다.

  3. 자료 넣기

    본문 텍스트로 만들 때

    + 새 기록 → 빈 기록을 고르고, 본문을 쓰거나 붙여 넣습니다. 한 줄에 한 문장이면 가장 깔끔하게 나옵니다. 다 넣었으면 오른쪽 아래 ▶ 전체 처리를 누릅니다.

    PPT · PDF로 만들 때

    파일을 이어온 창에 끌어다 놓거나, + 새 기록 → PPT · PDF 불러오기로 고릅니다. 자동 진행이 켜져 있으면 왼쪽 대기열에 들어가 바로 시작합니다. 여러 개를 한꺼번에 놓으면 차례로 처리합니다.

    맨 앞 OCR 칩이 켜져 있으면 그림이나 스캔본 속 글자도 제미나이 웹이 읽어 옵니다.

  4. 기다리기

    오른쪽 진행 칸에 번역 → 단어사전 → 음성 → HTML 순서로 진행 상황이 보입니다. 멈추고 싶으면 ■ 정지를 누릅니다.

    제미나이 창은 건드리지 마세요. 처리하는 동안 제미나이 창이 잠깐씩 떴다 닫힙니다. 그 창을 닫거나 그 안에서 무엇을 누르면 작업이 멈출 수 있습니다. 다른 일을 하며 기다려도 됩니다.

  5. 결과 열기

    끝나면 기록이 왼쪽 완료로 옮겨지고, 위쪽에 수업 자료가 준비됐어요 카드가 나옵니다. HTML 열기를 누르면 교실 화면에 띄울 수업 자료가 브라우저에서 열립니다.

막혔을 때

오른쪽 위가 빨갛게 '로그인 필요'로 바뀌었어요
구글 로그인이 풀린 것입니다. 1번처럼 다시 로그인합니다. 처리하는 도중에 풀리면 이어온이 창을 띄워 물어보고, 로그인하면 하던 곳부터 이어서 합니다.
전체 처리 버튼이 흐려서 눌리지 않아요
본문이 비어 있을 때 그렇습니다. 본문을 넣거나 기록을 하나 골라 주세요.
처리하다 멈췄어요
기록 위에 빨간 안내가 뜹니다. 다시 실행을 누르면 그 기록을 다시 처리합니다. 이유는 로그 보기에서 볼 수 있습니다.
번역 칩에 '웹'이 아닌 다른 글자가 있어요
칩 오른쪽 ▾를 눌러 위의 한꺼번에 고르기를 따라요를 고르면 제미나이 웹으로 돌아옵니다.
화면은 이어온 3.12 기준이며, 예시 기록으로 찍었습니다. 버전에 따라 조금 다를 수 있습니다.
